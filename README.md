## Project Overview

ToyWorld is an E-commerce Database Management System developed to manage the online toy store efficiently. 
The system stores and manages customer details, products, orders, payments, and inventory using a relational database.


## Objectives

- Manage customer information.
- Store product details.
- Process customer orders.
- Maintain inventory records.
- Track payments and order status.
- Reduce data redundancy through database normalization.


## Features

- Customer Registration and Login
- Product Management

- Shopping Cart
- Order Management
- Payment Management
